# Oasis Infobyte Internship - Security Analyst (OIBSIP)

This repository contains all completed tasks for the Security Analyst Internship Track at Oasis Infobyte.

## Completed Tasks

1. **Task 1: Basic Network Scanning with Nmap**
   - Perform network scanning, service detection, and OS detection using Nmap.
   - Folder: `Task1_NmapScanning/`

2. **Task 2: Basic Firewall Configuration with UFW**
   - Set up and configure Linux Uncomplicated Firewall (UFW) rules and testing.
   - Folder: `Task2_UFWFirewall/`

3. **Task 4: Research Report - Common Network Security Threats**
   - Technical research report covering DoS/DDoS, MITM, IP Spoofing, and mitigation strategies.
   - Folder: `Task4_NetworkThreatsReport/`

4. **Task 6: Research Report - Importance of Patch Management**
   - Detailed analysis on patch management lifecycle, risks, and best practices.
   - Folder: `Task6_PatchManagementReport/`
